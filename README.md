# HexInspect

A lightweight, high-performance binary file inspector written in Rust. This tool allows you to generate random binary files for testing and inspect existing files using a standard 16-byte aligned "hex dump" view.

## Features
- **Binary Generation**: Create random binary files of a specified size (KB).
- **Hex Inspector**: View files in a structured, 16-byte aligned layout with offset tracking and ASCII preview.
- **Minimal Dependencies**: Designed to prioritize the Rust standard library for core I/O operations.
